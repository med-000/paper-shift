# プロダクト概要と技術方針

PaperShiftは英語論文などのPDFを入力し、図・表・数式とページレイアウトをできるだけ保った日本語版PDFを生成するオープンソースのCLIツールです。まずは各利用者のPCで実行します。利用者自身がSign in with ChatGPTで認証し、承認したChatGPTプランで本文を翻訳する構想です。開発者がAI推論の利用料金を負担しないことを必須条件とします。プランの資格・モデル・利用制限は[技術的な懸念](feasibility.md)に記載した検証で確認します。

## 目指す体験

- 手元の英語PDFを指定し、日本語版PDFを保存する。
- 図・表・数式と、その内部の軸ラベルや文字は翻訳せず、元の位置・大きさで残す。本文だけを日本語にする。
- PDFの解析と生成は手元のPCで行い、OpenAIには翻訳に必要なテキストのみを送る。
- 将来的にWeb PDFの取り込み、原文と訳文の切り替え、並列表示、選択翻訳、要約、複数プロバイダーを追加する。

## 暫定的な技術構成

- **Python 3.11以降 / uv**：ローカルでのOAuthコールバック受信、PDF処理、ファイル入出力、CLI開発。
- **PyMuPDF**：文字・座標・フォント情報の抽出、元ページの編集、日本語版PDFの生成。図を壊さず本文だけを処理できるか実PDFで検証する。
- **日本語フォント**：訳文の配置と埋め込み。配布条件を確認する。
- **Sign in with ChatGPT + Responses API**：ユーザーの承認済みプランによる翻訳の検証対象。
- **端末内ストレージ（未定）**：認証情報の保護、翻訳結果の再利用、一時ファイルの管理。

PDF処理と翻訳プロバイダーは分けますが、汎用フレームワークは先に作りません。MVPはOpenAIのみとし、後にGoogleなどを追加できる構成を目指します。React/TypeScriptのUI、WXTによるChrome拡張機能、Cloudflareまたは自宅サーバーでのWebサービス化は後の候補です。リモート型でChatGPTプランを利用できるかは別途確認が必要です。

## ライセンス方針

PaperShiftのソースコードは[AGPLv3](../LICENSE)で公開します。PyMuPDFはAGPLv3版を利用します。同梱のNotoフォントは各フォントのSIL Open Font Licenseに従います。生成した翻訳済みPDFにAGPLv3が自動的に適用されるわけではありません。

## MVPの完成条件

- Windows/macOSのクリーン環境で、Python・uv・Gitを別途インストールせずに`pshift`を起動できる。
- 手元の英語テキストPDFの本文を、ユーザー自身のChatGPT認証と承認済みプランで日本語に翻訳し、一般的なPDFビューアで読める日本語版PDFとして保存できる。
- 図・表・数式とその内部の文字は翻訳せず、元の位置・大きさで可能な限り保持する。
- 開発者負担のAI推論費用を発生させない。

Webサービス、Chrome拡張機能、画面上での原文・訳文切り替えはMVPの必須条件に含めません。
